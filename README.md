# מחלקת משק - מערכת חלוקת ציוד

אתר עצמאי למעקב אחר חלוקת ציוד ואספקה למחלקות: הזנה ידנית של מסירות, עם היסטוריה מלאה של מה נלקח ועל ידי מי.

## יכולות

- **חלוקה והיסטוריה (`/`)** – טבלת היסטוריה בראש העמוד (מחלקה × פריט, עם סיכומים), טופס הזנה ידנית של מסירה חדשה, ויומן מסירות כרונולוגי.
- **מחלקות (`/departments`)** – ניהול קטלוג המחלקות המקבלות ציוד (הוספה, השבתה, מחיקה).
- **פריטים (`/items`)** – ניהול קטלוג הפריטים הניתנים לחלוקה (הוספה, השבתה, מחיקה).
- **קישור צפייה בלבד** – הוספת `?view=1` לכתובת האתר נותנת גישת קריאה בלבד לצמיתות: כפתורי ההוספה/עריכה/מחיקה מוסתרים, וגם ניסיון ישיר לשמור נחסם בשרת.

## הרצה מקומית

```bash
npm install
npx prisma generate
npx prisma migrate dev   # יצירת מסד הנתונים המקומי (SQLite)
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

## טכנולוגיות

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma ORM + SQLite מקומי לפיתוח, Turso (libSQL) אופציונלי בפרודקשן
- Server Actions לכל פעולות היצירה/עדכון/מחיקה
